# 🤝 Contributing to Supread Doc Community

First off, thank you for considering contributing to **Supread Doc Community**! It’s people like you that make this community an amazing place to learn and grow.

---

## 🚀 How Can You Contribute?

You can contribute in several ways:
1. **Writing Docs:** Adding new topics or expanding existing documentation.
2. **Code Examples:** Adding clear, bug-free, PEP 8-compliant Python code snippets.
3. **Fixing Typos & Errors:** Improving clarity, grammar, or fixing broken links.
4. **Issue Creation:** Reporting inaccurate content or suggesting new topics.

## 📝 Rules for Documentation Contributors

When adding or updating a doc file, please ensure you follow these standards:

1. **Format:** Use clean Markdown formatting (`#`, `##`, code blocks ```python).
2. **Structure:**
   - **Title & Overview:** Explain what the concept is and why it is used.
   - **Analogy:** Include a real-world simple analogy.
   - **Code Examples:** Tested, working Python code with comments.
   - **Common Pitfalls:** What mistakes do beginners make here?
3. **Accuracy:** Test every code snippet in Python 3.10+ before submitting.
4. **Originality:** Do not copy-paste directly from other websites or books. Explain in your own clear words.

## 🙋 How to Claim a Topic?

1. Check the [Issues](../../issues) tab or open a new issue titled: `Docs: Writing [Topic Name]`.
2. Once assigned, create a branch in your fork: `docs/topic-name`.
3. Write the markdown file in its designated folder listed above.
4. Update the status checklist in this README file from `[ ]` to `[✅]`.
5. Submit a Pull Request!
